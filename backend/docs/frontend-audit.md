# Placement Bridge — Existing Frontend Audit (Phase 0)

## 1. Existing Frontend Overview
- **Framework & Styling**: React 19 + TypeScript + Vite 6 + Tailwind CSS v4 (`@import "tailwindcss";` in `/src/index.css`).
- **Routing / Navigation Model**: State-driven SPA navigation (`currentPath: NavigationPath` in `/src/App.tsx` for Student Portal; `section: AdminSection` in `/src/components/AdminConsoleApp.tsx` for Admin Console), gated by role-isolated authentication (`loginPortalMode: 'student' | 'admin'`).
- **Current State Management**: Top-level React `useState` / `useEffect` in `/src/App.tsx` and `/src/components/AdminConsoleApp.tsx`, hydrated partially from `/api/*` endpoints in `/server.ts` and seeded fallback constants in `/src/data/placementData.ts`.
- **Current Mock / Static Data Location**: `/src/data/placementData.ts` (`INITIAL_PROFILE`, `INITIAL_COMPANIES`, `INITIAL_SKILL_GAPS`, `INITIAL_TASKS`, `APTITUDE_QUESTIONS`, `CODING_PROBLEMS`, `INITIAL_APPLICATIONS`, `INITIAL_STUDY_MODULES`, `INTERVIEW_ARCHIVES`, `RESOURCE_ITEMS`, `INITIAL_SETTINGS`).
- **Existing API Calls in Frontend**:
  - Auth: `GET /api/auth/challenge`, `POST /api/auth/admin/login`, `POST /api/auth/student/email`, `POST /api/auth/student/continue`, `GET /api/auth/me`, `POST /api/auth/logout`
  - Student sync: `GET /api/student/bootstrap`, `POST /api/student/applications`
  - Admin sync: `GET /api/admin/dashboard`, `PUT /api/admin/profile`, `POST /api/admin/drives`, `DELETE /api/admin/drives/:id`, `PATCH /api/admin/applications/:id`
  - AI endpoints: `POST /api/ai/chat`, `POST /api/ai/ats-audit`, `POST /api/ai/mock-interview`, `POST /api/ai/code-review`
- **Dedicated Frontend API Client Layer**: Not yet extracted (`fetch` called directly in components). In Phase 1+, `/src/services/api/client.ts` and domain modules will wrap `/api/v1/*` with adapters so **zero existing UI/UX components are redesigned or broken**.
